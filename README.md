# 繁梦 AI 工具箱（FMKJ AI Copilot）

> 面向 Windows 和 macOS 的 AI 编程工具箱：一键安装 Codex、一键汉化成简体中文、一键配置 GPT / DeepSeek 模型。

**官方下载站：<https://copilot.fmkj.top/download>** · 新手指导：<https://copilot.fmkj.top/download/guide>

## 主要功能

- **一键安装 Codex**：自动检测本机环境，缺什么装什么，安装进度实时显示。
- **Codex 中文汉化**：一键下载语言包，生成桌面「Codex 简体中文版」；Codex 更新后回工具箱再点一次「开始汉化」即可恢复中文。
- **登录即用，免配置 API Key**：登录账户后自动准备模型配置，点击「启动 Codex」直接对话，不需要手动填写 Key 和接口地址。
- **多模型按等级路由**：支持 GPT 系列与 DeepSeek 模型，按账户等级与订阅自动选择可用模型，升级套餐后自动生效，无需重新登录。
- **积分与订阅**：兑换码兑换、积分余额与消费记录查看、订阅卡和模型权益包管理，价格表实时同步。
- **应用管理**：同时管理 Codex、Claude Code 与 WorkBuddy，查看服务与客户端状态。

## 安装与使用

1. 下载安装版，双击运行。若出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」；系统询问是否允许更改时点「是」。
2. 出现「正在安装 WebView2」且进度条长时间不动时请耐心等待，不要强制关闭。
3. Windows 打开工具箱，进入 Codex 页面：「安装 Codex」→「开始汉化」→「启动 Codex」。以后可直接双击桌面「Codex 简体中文版」。
4. 登录账户，选择钱包积分或已购订阅，客户端自动准备模型配置后即可开始对话。
5. macOS 用户下载 Apple Silicon DMG，将应用拖入「应用程序」。当前包未做 Apple 公证。
6. 有兑换码时，在 Codex 页面点「兑换并配置」，整段粘贴兑换码。

遇到问题请查看 [新手指导](https://copilot.fmkj.top/download/guide) 的常见问题，或在本仓库提交 Issue。
